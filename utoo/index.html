快速安装指南

几分钟内即可开始使用 uTools 提升效率

1

下载客户端

访问官方网站或应用商店，下载适合您操作系统的 uTools 安装包（Windows, macOS, Linux）。安装程序体积小巧，运行迅速。

2

注册并登录

安装完成后，打开 uTools。使用邮箱或第三方账号注册并登录。登录后即可开启跨设备同步功能。

3

安装插件

按下 Ctrl+Alt+U 唤起工具箱，点击“插件市场”图标。在搜索框中输入您需要的工具名称，点击安装即可。

常见问题

uTools 是免费的吗？ +
是的，uTools 基础功能完全免费，包括全局搜索、剪贴板历史和基础工具。部分高级插件可能需要付费或观看广告解锁。
如何卸载插件？ +
在 uTools 工具栏中，找到您想卸载的插件，右键点击选择“卸载”即可。您也可以在插件市场管理中批量管理已安装的插件。
支持哪些操作系统？ +
uTools 支持最新的 Windows 10/11、macOS (10.13+) 以及主流的 Linux 发行版。
快捷键冲突怎么办？ +
uTools 支持自定义快捷键。如果您发现默认的 Ctrl+Alt+U 与其他软件冲突，可以在设置中修改唤起快捷键。
